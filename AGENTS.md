# pp-ocr-mnn — Project Rules (binding for ALL agents)

PaddleOCR inference ported to MNN. One C++ codebase, every platform, every backend,
**every PP-OCR model variant (v4 / v5 / v6, mobile / server / tiny / small / medium,
plus language-specific rec models, doc-rec, seal-det, and the PP-LCNet textline-orientation cls)**.

Decision-maker agent (the one that created this file's workflow) splits tasks, reviews, and merges.
Executor agents work on branches `ws/<task>` and NEVER push to main directly.

## Goal

Run the full PP-OCR family via MNN on Windows / Linux / macOS / Android / iOS,
auto-selecting CPU / OpenCL / Vulkan / Metal / CoreML / NNAPI / CUDA.

The acceptance matrix is the baseline under `/root/ppocr_reference/` (**811 cells, all mandatory**):

| Block | Content | Cells |
|---|---|---|
| Main matrix | 7 det × 7 rec × 16 langs | 784 |
| Lang-specific rec | 12 language rec models (v5_mobile_det, native + en imgs) | 21 |
| Doc rec | PP-OCRv4_server_rec_doc × v4_server_det (5 langs) | 5 |
| Seal det × 2 | PP-OCRv4 mobile/server seal det on seal imgs | 2 |
| Strip | ta / te rec-only synthesized strips | 2 |

Every cell must pass CER ≤ 0.05 vs its own baseline (see `manifest_full.json`).
cls (textline orientation) is NOT in the baseline (`use_textline_orientation=False`);
it ships as a first-class module, default off, validated separately on rotated images.

## Hard rules

1. **Do not modify `third_party/MNN/`.** Submodule of `alibaba/MNN@2.9.x` (pinned 35af91b, 2.9.1).
   File upstream for bugs. Its `build/` dir is local-only (gitignored), safe to rebuild.
2. **Use the PaddleOCR models in `/root/ppocr_models/` (+ cls in `~/.paddlex/official_models/PP-LCNet_x1_0_textline_ori/`) as-is.**
   Do not re-download, retrain, or finetune. The catalog is the contract.
3. **Every model variant must be supported.** 811-cell matrix is hard, not a wishlist.
   If a model converts or runs badly, fix OUR code (preprocess / postprocess / conversion).
4. **Preprocess/postprocess must match each model's `inference.yml`.** Key facts (verified):
   - det DB params: v4/v5 (mobile & server) = thresh 0.3 / box 0.6 / unclip 1.5, resize_long 960;
     v6 (tiny/small/medium) = thresh 0.2 / box 0.4–0.45 / unclip 1.4, `DetResizeForTest: null`
     → type0 with limit_side_len 736 "min", 32-align; seal = 0.2 / 0.6 / 0.5, resize_long 736.
   - rec: ALL variants CTCLabelDecode, shape [3,48,320], norm `(x/255-0.5)/0.5`, BGR input,
     blank=0, space char appended last, dict differs per model (95–18708 entries).
   - cls PP-LCNet_x1_0_textline_ori: [3,80,160], ImageNet norm, labels 0°/180°, topk=1.
5. **No OpenCV.** `stb_image.h` for I/O, MNN `ImageProcess` for resize. DB postprocess
   (contours, minAreaRect, clipper offset, perspective warp) is hand-written C++.
6. **Business code is platform-agnostic.** `include/` and `src/` contain zero `#ifdef <platform>`.
   Platform code lives only under `platform/<name>/`. Backend selection lives only in `src/ppocr.cpp::pickBackend()`.
7. **One det model per language set; rec models are per-language.** Caps: mobile rec ≤ 25 MB,
   server rec ≤ 80 MB (.mnn).
8. **Baselines are versioned per combo.** Ground truth = `/root/ppocr_reference/<det>__<rec>/<lang>/ocr_results.json`.
   Compare like-for-like. Never regenerate baselines to make scores pass.
9. **Threading:** C ABI is multi-instance thread-safe. Synchronous core + optional async
   (internal worker). No global mutable state in `src/`.
10. **Model distribution:** runtime auto-download. Registry (JSON, generated by
    `tools/convert_models.py`) maps model name → url + sha256 + size + config. Mirror base URL
    comes from `PPORC_MNN_MIRROR` env (placeholder default). Local dir override always wins.
11. **Git discipline:** commit code only. NEVER `git add` weights, test data, baselines,
    build outputs, generated models (`models/`, `_downloads/`, `results/` are gitignored).
    Executors branch `ws/<task>`; only the decision-maker merges to `main` after review.
12. **Verification before claims:** every milestone ends with a green command
    (build + run + score) whose output is pasted in the review. No "should work".

## Layout

```
pp-ocr-mnn/
├── AGENTS.md                     ← this file (decision-maker may evolve it)
├── README.md
├── CMakeLists.txt                ← top-level; MNN backends chosen per platform
├── third_party/MNN/              ← submodule, do not touch (build/ is local, gitignored)
├── third_party/stb/              ← stb_image.h
├── models/                       ← local .mnn + dicts (gitignored)
├── include/ppocr/  src/          ← platform-agnostic core + C ABI
├── platform/{desktop,android,ios}/
└── tools/
    ├── convert_models.py         ← paddle → onnx → .mnn + registry.json (sha256, config)
    ├── extract_dict.py           ← inference.yml → dict + variant config
    ├── gen_reference.py          ← baseline maintenance (clean/synthesize)
    ├── gen_parallel.py           ← baseline generator (already done, 811 cells)
    ├── run_reference.py          ← run MNN CLI over matrix, write predictions
    └── score.py                  ← CER per cell, matrix report
```
